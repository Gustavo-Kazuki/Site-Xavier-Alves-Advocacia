# Xavier & Alves Advocacia

Website institucional e landing pages de aquisição da Xavier & Alves Advocacia.

## Desenvolvimento

Requer Node.js 22.

```sh
npm install
npm run dev
```

## Produção

O build padrão gera a saída nativa do Next.js utilizada pela Vercel:

```sh
npm run build
npm start
```

O projeto também preserva os comandos alternativos do ambiente Sites:

```sh
npm run dev:sites
npm run build:sites
npm run start:sites
```
